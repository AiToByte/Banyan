# 归档规则参考

本文件是 `banyan-archive` 技能的规则参考。周定义、切分、校验清单冻结于此，执行中不可静默修改。

## 周定义（冻结）

- 采用 ISO 8601：周一为周首，周日为周尾，周号为 ISO 周号（`Wxx`）。
- 周目录命名：`Wxx_MMDD-MMDD`（如 `W38_0914-0920`），MMDD 为本周一与本周日的月日。
- 跨月周归属：按**周一所在月份**落到对应 `YYYY-MM` 下（如 09-29周一~10-05 归 `2026-09/W40_0929-1005`）。
- 周 README 必须注明实际起止日期（如 `2026-09-14（一）~ 2026-09-20（日），ISO W38`）。

## 切分规则（冻结）

- 原子单位：`EXEC_LOG.md` 中 `### [YYYY-MM-DD HH:MM]` 开头的条目（含其下属 `- ` 行与代码块），不断条。
- 归属：按条目开始时间（`[...]` 内日期）的 ISO 周归属；无时间戳的备忘行跟随上一条。
- `# P...` 轮次标题行跟随其后第一条目同属一周；最终总结行归属本轮最后一条同周。
- 阈值：300 行或 60KB 或跨周一，任一命中即提示归档。

## 校验清单（搬运三步必查）

1. 搬运条目数（`### [` 计数）== 原文对应周条目数。
2. 首条与末条时间戳逐字一致。
3. 周切片文件名日期范围与周目录名一致。
4. 快照头四要素齐（快照时间/来源轮次/终态/跟踪表）。
5. 四级 README 互链可达（总→年→月→周）。
6. 根 `EXEC_LOG.md` 顶部归档指针行已更新，根只留活跃周条目。

## 术语一致

- `archive/`（周归档，自动）vs `docs/archive/`（manual 追溯，仅追溯）vs `plan/`（dated 跟踪表，本轮执行）。
- 状态符号沿用五态（⬜/🟡/✅/❌/⏭️）与 `TASK_PLAN.md` 映射（`[ ]/[-]/[x]/[!]/[s]`）。
