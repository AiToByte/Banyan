# Banyan 执行日志技能

> 版本：1.1（2026-09-16）
> 关联 Skill：`banyan-plan-track`（状态变更配套记日志）、`banyan-gate-verify`（门禁报告片段归档）。冲突时以本 SKILL.md 为准。

你是执行流水账的写入者。所有操作记录必须 append-only（只追加，不修改历史行），并双写到两个位置。

## 触发前置

1. 读取 `templates/log-fragments.md` 获取日志片段模板。
2. 读取当前 `EXEC_LOG.md` 确认最新条目位置。

## 双写位置

| 位置 | 文件 | 内容粒度 |
|------|------|----------|
| 详版 | `EXEC_LOG.md` | 完整记录（时间、操作、验证、问题、下一步） |
| 摘要版 | `plan/` 下 dated 计划文件文末 `##执行日志` | 一行摘要（`* YYYY-MM-DD：……`） |

## 日志片段类型

### 类型 1：步骤开始

追加到 `EXEC_LOG.md`：

```
### [YYYY-MM-DD HH:MM] 步骤 N 开始: [步骤描述]
- 计划操作：……
- 预期验证方式：……
```

### 类型 2：步骤完成（归档）

追加到 `EXEC_LOG.md`：

```
### [YYYY-MM-DD HH:MM] 步骤 N 已完成: [步骤描述]
- **实际操作**：修改了哪些文件、运行了哪些命令、关键参数
- **验证结果**：测试输出摘要 / 编译结果 / 功能确认（含数量，如 `97→99通过`）
- **遇到的问题与解决**：……
- **下一步建议**：……
```

追加到 `plan/` 下 dated 计划文件 `##执行日志`：

```
* YYYY-MM-DD：[步骤] 完成：[一句话摘要]（含门禁结果和数量变化）
```

### 类型 3：现场备忘（过程中）

追加到 `EXEC_LOG.md`：

```
[HH:MM] 实时调试/备忘: [发现……，决定采用……方案]
```

### 类型 4：教训记录

追加到 `EXEC_LOG.md` 完成条目的 `遇到的问题与解决` 段，同时追加到 dated 计划文件文末：

```
教训：[具体教训，如"复用同一网关+同源多 MID 单测会命中去重窗口误判，新子项须独立源端口"]
```

### 类型 5：最终总结

所有步骤完成后追加到 `EXEC_LOG.md` 末尾：

```
### 最终总结
- 整体完成情况：……
- 关键产出文件：……
- 遗留问题（如有）：……
- 验证结论：……
```

## 约束

- **append-only**：严禁修改 `EXEC_LOG.md` 或 dated 计划文件 `##执行日志` 节中的任何历史行。
- **数量必记**：完成日志必须包含测试数量变化（如 `88→91通过`）、bench 数值（如有）、lint 状态（`clippy零告警`）。
- **教训必写**：遇到非平凡问题时必须在 `遇到的问题与解决` 段写明教训，格式为 `教训：[一句话]`。
- **时间戳**：所有日志条目必须包含时间戳（`YYYY-MM-DD HH:MM` 或 `HH:MM`）。
- **双写原子**：详版和摘要版必须在同一次工具调用中完成。
