# 日志片段模板

本文件是 `banyan-exec-log` 技能的模板参考。

## 片段 1：步骤开始

```
### [YYYY-MM-DD HH:MM] 步骤 N 开始: [步骤描述]
- 计划操作：……
- 预期验证方式：……
```

## 片段 2：步骤完成

```
### [YYYY-MM-DD HH:MM] 步骤 N 已完成: [步骤描述]
- **实际操作**：修改了哪些文件、运行了哪些命令、关键参数
- **验证结果**：测试输出摘要 / 编译结果 / 功能确认（含数量）
- **遇到的问题与解决**：……
- **下一步建议**：……
```

## 片段 3：实时备忘

```
[HH:MM] 实时调试/备忘: [发现……，决定采用……方案。修改了文件：……]
```

## 片段 4：教训（嵌入在步骤完成中）

```
- **遇到的问题与解决**：[描述问题]
  教训：[一句话总结教训]
```

## 片段 5：最终总结

```
### 最终总结（任务全部完成后填写）
- 整体完成情况：[N]/[M] 步骤完成
- 关键产出文件：[文件列表]
- 遗留问题（如有）：[列表]
- 验证结论：[最终门禁状态]
```

## dated 计划文件文末日志格式

```
## 执行日志

* YYYY-MM-DD：建表，开始 [步骤]。
* YYYY-MM-DD：[步骤] 完成：[一句话摘要]（含门禁结果和数量变化）。
* YYYY-MM-DD：[步骤] 完成：[摘要]。教训：[教训]。
```
