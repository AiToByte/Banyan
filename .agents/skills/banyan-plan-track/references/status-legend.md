# 状态图例参考

本文件是 `banyan-plan-track` 技能的参考文档。

## 五态定义

| 符号 | 含义 | 允许的转换 |
|------|------|-----------|
| `⬜ 待开始` / `- [ ]` | 步骤未开始 | → `🟡` / → `⏭️` |
| `🟡 进行中` / `- [-]` | 正在执行 | → `✅` / → `❌` |
| `✅ 已完成` / `- [x]` | 已完成且门禁通过 | → 不可回退（除非用户明确要求） |
| `❌ 受阻` / `- [!]` | 受阻，需排查 | → `🟡`（修复后重试） |
| `⏭️ 跳过` / `- [s]` | 本轮跳过 | → 不可转换 |

## 双写同步规则

### 文件 A：dated 计划文件

状态列使用符号：`⬜` / `🟡` / `✅` / `❌` / `⏭️`

### 文件 B：TASK_PLAN.md

状态使用复选框：`- [ ]` / `- [-]` / `- [x]` / `- [!]` / `- [s]`

### 同步要求

- 两个文件中的步骤必须同名同序。
- 状态变更必须原子完成（同一工具调用）。
- 发现不一致时必须先修一致再施工。

## 备注列写法

### 通过时

`✅ 已完成` + 备注：`[测试数]通过 / [lint状态] / [关键数值]`

示例：`✅ 已完成 | 99通过（+2新单测）；clippy仅剩2条P3计划内；fmt clean`

### 受阻时

`❌ 受阻` + 备注：`[门]红灯：[原因]`

示例：`❌ 受阻 | clippy 3条新告警未消除`

### 跳过时

`⏭️ 另起一轮` + 备注：`本轮仅跟踪`
